# Сборка видео по образцу монтажа

Инструмент помогает собрать видео из ваших сырых клипов «под структуру» видео-референса:
он анализирует, как смонтирован образец (смена сцен, темп, текст на экране), подбирает под
каждую сцену подходящий ваш клип и автоматически собирает готовый ролик.

Работает на базе Claude API (Anthropic) — никакие другие платные сервисы не используются.

## Что нужно установить

### 1. Python

Нужен Python версии 3.10 или новее.

- **Windows**: скачайте установщик с [python.org/downloads](https://www.python.org/downloads/),
  запустите его и обязательно поставьте галочку **"Add Python to PATH"**.
- **macOS**: скачайте установщик с [python.org/downloads](https://www.python.org/downloads/)
  или установите через Homebrew: `brew install python`.
- **Linux**: обычно уже установлен. Проверить: `python3 --version`.

Проверить установку можно командой в терминале:

```
python --version
```

(на macOS/Linux иногда нужно писать `python3 --version`)

### 2. FFmpeg

Программа для работы с видео, без неё ничего не будет работать.

- **Windows**: скачайте сборку с [ffmpeg.org/download.html](https://ffmpeg.org/download.html)
  (раздел "Windows builds"), распакуйте архив, например, в `C:\ffmpeg`, и добавьте папку
  `C:\ffmpeg\bin` в переменную окружения PATH (Панель управления → Система → Дополнительные
  параметры системы → Переменные среды → Path → Изменить → Создать).
- **macOS**: `brew install ffmpeg` (нужен [Homebrew](https://brew.sh/)).
- **Linux (Ubuntu/Debian)**: `sudo apt install ffmpeg`.

Проверить установку:

```
ffmpeg -version
```

Если команда не найдена — значит FFmpeg не установлен или не добавлен в PATH.

## Как получить API-ключ Anthropic (Claude)

1. Зайдите на [console.anthropic.com](https://console.anthropic.com/) и зарегистрируйтесь
   или войдите.
2. Пополните баланс (обработка видео через Claude — платная, но недорогая; следите за
   расходами в разделе Billing).
3. Перейдите в раздел **API Keys** и нажмите **Create Key**.
4. Скопируйте ключ (он выглядит примерно так: `sk-ant-api03-...`). Ключ показывается только
   один раз — сохраните его в надёжном месте.

### Куда вставить ключ

В папке проекта создайте файл с именем `.env` (без расширения) и впишите в него одну строку:

```
ANTHROPIC_API_KEY=sk-ant-api03-ваш-ключ-здесь
```

Файл `.env` не должен попадать в git/репозиторий — храните его только у себя.

Альтернативно можно установить переменную окружения вручную перед запуском:

- **Windows (PowerShell)**: `$env:ANTHROPIC_API_KEY="sk-ant-..."`
- **macOS/Linux**: `export ANTHROPIC_API_KEY="sk-ant-..."`

## Установка зависимостей

Откройте терминал в папке проекта и выполните:

```
pip install -r requirements.txt
```

(на macOS/Linux иногда нужно `pip3 install -r requirements.txt`)

Рекомендуется использовать виртуальное окружение, чтобы не засорять систему:

```
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```
streamlit run app.py
```

После запуска в терминале появится ссылка (обычно `http://localhost:8501`), которая должна
открыться в браузере автоматически. Если этого не произошло — скопируйте ссылку и вставьте
в адресную строку браузера вручную.

## Как пользоваться

1. Загрузите видео-референс — пример монтажа, под который нужно подстроить ваши клипы.
2. Загрузите один или несколько своих сырых клипов.
3. Нажмите кнопку **"Собрать видео"**.
4. Дождитесь завершения всех этапов (анализ референса → анализ клипов → составление плана
   монтажа → сборка видео). Это может занять несколько минут в зависимости от длины видео.
5. Просмотрите результат прямо на странице и скачайте готовый .mp4 файл.

## Частые проблемы и их решение

**"Не найден ключ ANTHROPIC_API_KEY"**
Проверьте, что файл `.env` находится в той же папке, что и `app.py`, и содержит строку
`ANTHROPIC_API_KEY=...` без кавычек и пробелов вокруг знака `=`. После изменения `.env`
перезапустите Streamlit (остановите его в терминале сочетанием `Ctrl+C` и запустите заново).

**"ffmpeg: command not found" / "не является внутренней или внешней командой"**
FFmpeg не установлен или не добавлен в PATH. Проверьте установку командой `ffmpeg -version`
в новом окне терминала (после установки нужно открыть терминал заново). См. раздел
"Что нужно установить" выше.

**"FFmpeg не смог нарезать кадры" / "FFmpeg не смог собрать видео"**
Скорее всего, видеофайл повреждён или имеет нестандартный формат/кодек. Попробуйте
переконвертировать видео в стандартный .mp4 (например, через любой бесплатный конвертер)
и загрузить заново.

**"Не удалось извлечь корректный JSON из ответа Claude"**
Иногда модель может ответить не в ожидаемом формате, особенно на очень длинных или сложных
видео. Попробуйте запустить сборку ещё раз — обычно со второй попытки всё получается.
Если ошибка повторяется — попробуйте укоротить видео-референс или взять референс попроще.

**Процесс идёт очень долго**
Анализ через Claude API занимает время пропорционально длине видео и количеству клипов —
чем длиннее видео, тем больше кадров нужно отправить и обработать. Для очень длинных видео
(больше 3-5 минут) обработка может занять несколько минут.

**Ошибка про превышение лимита / баланс API**
Проверьте баланс на [console.anthropic.com](https://console.anthropic.com/) в разделе
Billing — возможно, закончились средства на счету.

**"ModuleNotFoundError: No module named ..."**
Зависимости установлены не полностью или не в то окружение. Убедитесь, что вы активировали
виртуальное окружение (если используете) и повторно выполните `pip install -r requirements.txt`.

## Структура проекта

- `common.py` — общие функции (нарезка на кадры, обращение к Claude API, работа с JSON).
- `analyze_reference.py` — анализ видео-референса.
- `analyze_clips.py` — анализ сырых клипов.
- `match_scenes.py` — составление монтажного плана (EDL).
- `assemble_video.py` — сборка финального видео по EDL.
- `app.py` — веб-интерфейс на Streamlit.
- `requirements.txt` — зависимости Python.
