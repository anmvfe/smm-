# SMM-помощник — SaaS-приложение для SMM-специалиста

Приложение помогает вести нескольких клиентов и для каждого из них через Claude API
генерировать контент-план, тексты постов, сценарии рилсов и рекламные тексты, а также
собирать видео по образцу монтажа. Всё хранится локально в JSON-файлах — можно в любой
момент открыть, отредактировать вручную или удалить сгенерированный контент.

Работает на базе Claude API (Anthropic) — никакие другие платные сервисы не используются.
Все разделы используют один и тот же ключ `ANTHROPIC_API_KEY`.

## Как устроено приложение

Слева — боковая панель (сайдбар) с навигацией по разделам, а сверху в ней — выбор
**"активного клиента"**: клиент, с которым вы сейчас работаете. Все разделы, кроме «Клиенты»
и «Обработка видео», всегда работают с текущим активным клиентом — его не нужно выбирать
заново в каждом разделе.

Разделы:

1. **Клиенты** — карточки клиентов: имя, ссылка на соцсеть (справочно), описание бизнеса,
   tone of voice, цели по контенту.
2. **Контент-план** — план постов на 2 недели с возможностью редактировать, перегенерировать
   и удалять отдельные строки.
3. **Сценарии для рилсов** — текстовые сценарии (раскадровка по секундам), без работы с видео.
4. **Обработка видео** — существующий модуль сборки видео по образцу монтажа (не изменён).
5. **Посты и описания** — тексты постов: подпись, хэштеги, призыв к действию.
6. **Реклама** — рекламные тексты для платных кампаний.

## Что нужно установить

### 1. Python

Нужен Python версии 3.10 или новее.

- **Windows**: скачайте установщик с [python.org/downloads](https://www.python.org/downloads/),
  запустите его и обязательно поставьте галочку **"Add Python to PATH"**.
- **macOS**: скачайте установщик с [python.org/downloads](https://www.python.org/downloads/)
  или установите через Homebrew: `brew install python`.
- **Linux**: обычно уже установлен. Проверить: `python3 --version`.

Проверить установку можно командой в терминале:

```
python --version
```

(на macOS/Linux иногда нужно писать `python3 --version`)

### 2. FFmpeg

Нужен только для раздела «Обработка видео» — без него остальные разделы (клиенты,
контент-план, сценарии, посты, реклама) работают нормально.

- **Windows**: скачайте сборку с [ffmpeg.org/download.html](https://ffmpeg.org/download.html)
  (раздел "Windows builds"), распакуйте архив, например, в `C:\ffmpeg`, и добавьте папку
  `C:\ffmpeg\bin` в переменную окружения PATH (Панель управления → Система → Дополнительные
  параметры системы → Переменные среды → Path → Изменить → Создать).
- **macOS**: `brew install ffmpeg` (нужен [Homebrew](https://brew.sh/)).
- **Linux (Ubuntu/Debian)**: `sudo apt install ffmpeg`.

Проверить установку:

```
ffmpeg -version
```

Если команда не найдена — значит FFmpeg не установлен или не добавлен в PATH.

## Как получить API-ключ Anthropic (Claude)

1. Зайдите на [console.anthropic.com](https://console.anthropic.com/) и зарегистрируйтесь
   или войдите.
2. Пополните баланс (использование Claude API — платное, но недорогое; следите за расходами
   в разделе Billing).
3. Перейдите в раздел **API Keys** и нажмите **Create Key**.
4. Скопируйте ключ (он выглядит примерно так: `sk-ant-api03-...`). Ключ показывается только
   один раз — сохраните его в надёжном месте.

### Куда вставить ключ

В папке проекта создайте файл с именем `.env` (без расширения) и впишите в него одну строку:

```
ANTHROPIC_API_KEY=sk-ant-api03-ваш-ключ-здесь
```

Файл `.env` не должен попадать в git/репозиторий — храните его только у себя.

Альтернативно можно установить переменную окружения вручную перед запуском:

- **Windows (PowerShell)**: `$env:ANTHROPIC_API_KEY="sk-ant-..."`
- **macOS/Linux**: `export ANTHROPIC_API_KEY="sk-ant-..."`

## Установка зависимостей

Откройте терминал в папке проекта и выполните:

```
pip install -r requirements.txt
```

(на macOS/Linux иногда нужно `pip3 install -r requirements.txt`)

Рекомендуется использовать виртуальное окружение, чтобы не засорять систему:

```
python -m venv venv
# Windows:
venv\Scripts\activate
# macOS/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

## Запуск

```
streamlit run app.py
```

После запуска в терминале появится ссылка (обычно `http://localhost:8501`), которая должна
открыться в браузере автоматически. Если этого не произошло — скопируйте ссылку и вставьте
в адресную строку браузера вручную.

## Развёртывание на Streamlit Community Cloud

Приложение можно бесплатно опубликовать на [share.streamlit.io](https://share.streamlit.io/),
чтобы им можно было пользоваться прямо из браузера, без установки Python на свой компьютер.

1. **Залейте код в GitHub.** Создайте репозиторий на [github.com](https://github.com/) и
   загрузите в него все файлы проекта (`app.py`, `common.py`, `requirements.txt`,
   `packages.txt` и остальные `.py`-файлы). Файл `.env` (если он у вас есть локально) в
   репозиторий заливать не нужно — он и так исключён через `.gitignore`.
2. **Зайдите на [share.streamlit.io](https://share.streamlit.io/)** и войдите через свой
   GitHub-аккаунт.
3. Нажмите **"New app"**, выберите:
   - **Repository** — ваш репозиторий с проектом;
   - **Branch** — ветку, в которой лежит код (обычно `main`);
   - **Main file path** — `app.py`.
4. Перед запуском (или сразу после, через **⋮ → Settings → Secrets**) добавьте ключ Claude
   API в раздел **Secrets**. Формат такой же, как в `.env`, но в синтаксисе TOML:
   ```
   ANTHROPIC_API_KEY = "sk-ant-api03-ваш-ключ-здесь"
   ```
   Пример такого файла есть в `.streamlit/secrets.toml.example` — можно скопировать формат
   оттуда. Приложение само найдёт ключ через `st.secrets`, ничего менять в коде не нужно.
5. Нажмите **"Deploy"** и дождитесь сборки (обычно 1-3 минуты). Streamlit Cloud автоматически
   установит зависимости из `requirements.txt`, а системный пакет `ffmpeg` — из `packages.txt`
   (он там уже указан, отдельно ничего делать не нужно).
6. После сборки приложение откроется по адресу вида
   `https://<имя-приложения>.streamlit.app` — эту ссылку можно использовать и делиться ей.

При обновлении кода в GitHub-репозитории (например, `git push` в ту же ветку) Streamlit Cloud
автоматически пересоберёт и перезапустит приложение.

**Важно про хранение данных на Cloud:** файловая система Streamlit Community Cloud —
временная и может очищаться при пересборке приложения. Для надёжного долговременного
хранения клиентов и сгенерированного контента используйте локальный запуск (тогда все
файлы в папке `data/` сохраняются у вас на диске) либо периодически скачивайте нужные
данные (например, контент-план через кнопку "Скачать CSV").

## Как пользоваться

### 1. Клиенты

Раздел для ведения карточек клиентов (брендов), с которыми вы работаете.

1. Откройте раздел **"Клиенты"** в сайдбаре слева.
2. Заполните форму **"Добавить нового клиента"**:
   - **Имя / бренд** — как называется клиент;
   - **Ссылка на соцсеть** — необязательно; вставьте ссылку на Instagram/TikTok/VK и т.д.
     Обратите внимание: эта ссылка сохраняется **только для справки** — приложение не
     переходит по ней и не анализирует профиль автоматически, это просто заметка для вас;
   - **Краткое описание бизнеса и ниши** — пару предложений о том, чем занимается бренд и
     в какой сфере работает;
   - **Tone of voice** — выберите из списка (дружелюбный / экспертный / дерзкий) или
     укажите свой вариант через "другое (указать вручную)";
   - **Что хочу получить (цели по контенту)** — опишите своими словами, чего вы хотите
     добиться контентом: больше подписчиков, продажи, узнаваемость и т.д. Этот текст
     учитывается при каждой генерации контента для клиента.
3. Нажмите **"Добавить клиента"** — карточка появится в списке ниже.
4. Внутри карточки клиента доступны кнопки **"Редактировать"** (откроет поля для
   изменения — не забудьте нажать "Сохранить изменения") и **"Удалить клиента"**
   (удалит клиента и весь сгенерированный для него контент — контент-план, сценарии,
   посты, рекламу).
5. Все клиенты хранятся в файле `data/clients.json` прямо на диске (без базы данных).

После добавления клиента выберите его в выпадающем списке **"Активный клиент"** в верхней
части сайдбара — все остальные разделы будут работать именно с ним.

### 2. Контент-план

1. Убедитесь, что выбран нужный активный клиент.
2. Откройте раздел **"Контент-план"**.
3. Нажмите **"Сгенерировать новый контент-план"** — Claude составит план публикаций на
   2 недели вперёд: для каждого поста будет дата, тема, формат (сторис/рилс/карусель/
   статичный пост) и короткое обоснование. Новый план заменяет предыдущий.
4. План отображается таблицей, где каждая строка редактируемая:
   - измените любое поле прямо в строке и нажмите значок **💾**, чтобы сохранить именно эту строку;
   - нажмите значок **🔄**, чтобы попросить Claude придумать новую идею для этой же даты
     взамен текущей (остальные строки не трогаются);
   - нажмите **"🗑️ Удалить строку"**, чтобы убрать пост из плана.
5. Через блок **"➕ Добавить строку вручную"** можно добавить свой пост в план без обращения
   к Claude.
6. Кнопка **"Скачать контент-план как CSV"** сохраняет план в файл, который можно открыть
   в Excel или Google Таблицах.

### 3. Сценарии для рилсов

Этот раздел создаёт только **текстовый** сценарий (раскадровку) — видео при этом не
загружается и не монтируется.

1. Выберите тему из уже сгенерированного контент-плана — либо выберите
   **"Ввести тему вручную"** и опишите идею рилса своими словами (например: "до/после
   результата услуги", "разбор частого вопроса клиентов", "закулисье процесса производства").
2. Настройте желаемую длительность ползунком (в секундах).
3. Нажмите **"Сгенерировать сценарий"** — Claude пришлёт сценарий с раскадровкой по секундам:
   что происходит в кадре, что говорить, какой текст выводить на экран в каждой сцене.
   Сценарий сразу сохраняется в список ниже.
4. В списке **"Сохранённые сценарии"** каждый сценарий можно открыть, отредактировать текст
   вручную прямо в текстовом поле и нажать **"Сохранить изменения"**, либо нажать
   **"Удалить сценарий"**.

### 4. Обработка видео

Это уже знакомый видео-модуль: загрузите видео-референс (образец монтажа) и свои сырые
клипы, нажмите **"Собрать видео"** — сервис проанализирует референс через Claude, подберёт
под него ваши клипы и соберёт готовое видео, которое можно посмотреть и скачать. Этот раздел
не привязан к активному клиенту и работает так же, как раньше.

### 5. Посты и описания

1. Выберите тему из контент-плана или введите свою тему вручную, выберите формат поста.
2. Нажмите **"Сгенерировать текст поста"** — Claude напишет подпись (caption), подходящий
   набор хэштегов и призыв к действию, выдержанные в tone of voice активного клиента. Пост
   сразу сохраняется в список ниже.
3. В списке **"Сохранённые посты"** каждый пост можно открыть, отредактировать текст вручную
   и сохранить изменения, либо удалить.

### 6. Реклама

1. Укажите тему / оффер рекламной кампании (например: "скидка 20% на первую консультацию").
2. Выберите формат объявления: **"Instagram/Facebook объявление"** (обычное объявление в
   ленте) или **"Короткий текст для сторис-рекламы"** (короче и динамичнее).
3. Нажмите **"Сгенерировать рекламный текст"** — Claude составит заголовок, основной текст,
   три разных варианта hook (цепляющей первой фразы) и призыв к действию. Объявление сразу
   сохраняется в список ниже.
4. В списке **"Сохранённые рекламные тексты"** каждое объявление можно открыть,
   отредактировать любое поле (заголовок, текст, каждый hook, CTA) вручную и сохранить
   изменения, либо удалить.

## Частые проблемы и их решение

**"Не найден ключ ANTHROPIC_API_KEY"**
Локально: проверьте, что файл `.env` находится в той же папке, что и `app.py`, и содержит
строку `ANTHROPIC_API_KEY=...` без кавычек и пробелов вокруг знака `=`. После изменения `.env`
перезапустите Streamlit (остановите его в терминале сочетанием `Ctrl+C` и запустите заново).
На Streamlit Community Cloud: проверьте раздел **⋮ → Settings → Secrets** — ключ должен быть
в формате `ANTHROPIC_API_KEY = "sk-ant-..."` (с кавычками, это синтаксис TOML).

**«Сначала выберите или добавьте активного клиента»**
Разделы «Контент-план», «Сценарии для рилсов», «Посты и описания» и «Реклама» работают только
с выбранным активным клиентом. Перейдите в раздел «Клиенты», добавьте клиента, затем выберите
его в выпадающем списке «Активный клиент» вверху сайдбара.

**"ffmpeg: command not found" / "не является внутренней или внешней командой"**
Эта ошибка касается только раздела «Обработка видео». FFmpeg не установлен или не добавлен
в PATH. Проверьте установку командой `ffmpeg -version` в новом окне терминала (после
установки нужно открыть терминал заново). См. раздел "Что нужно установить" выше.

**"FFmpeg не смог нарезать кадры" / "FFmpeg не смог собрать видео"**
Скорее всего, видеофайл повреждён или имеет нестандартный формат/кодек. Попробуйте
переконвертировать видео в стандартный .mp4 (например, через любой бесплатный конвертер)
и загрузить заново.

**"Не удалось извлечь корректный JSON из ответа Claude"**
Иногда модель может ответить не в ожидаемом формате. Попробуйте запустить генерацию ещё раз —
обычно со второй попытки всё получается.

**Процесс идёт очень долго**
Обработка видео занимает время пропорционально длине видео (нужно отправить и обработать
много кадров). Генерация текста (контент-план, посты, сценарии, реклама) обычно занимает
несколько секунд — если дольше, проверьте соединение с интернетом.

**Ошибка про превышение лимита / баланс API**
Проверьте баланс на [console.anthropic.com](https://console.anthropic.com/) в разделе
Billing — возможно, закончились средства на счету.

**"ModuleNotFoundError: No module named ..."**
Зависимости установлены не полностью или не в то окружение. Убедитесь, что вы активировали
виртуальное окружение (если используете) и повторно выполните `pip install -r requirements.txt`.

**После перезапуска приложения пропали клиенты или контент**
На Streamlit Community Cloud файловая система временная (см. раздел про развёртывание выше).
При локальном запуске данные должны сохраняться в папке `data/` между запусками — если они
пропадают, проверьте, что вы каждый раз запускаете `streamlit run app.py` из одной и той же
папки проекта.

## Структура проекта

**Общее:**
- `common.py` — общие функции (ключ Claude API, нарезка кадров, извлечение JSON, работа с JSON-файлами).
- `storage.py` — общее JSON-хранилище сущностей, привязанных к клиенту (контент-план, сценарии, посты, реклама).
- `app.py` — точка входа Streamlit-приложения: сайдбар-навигация и выбор активного клиента.

**Клиенты:**
- `clients.py` — хранение клиентов в `data/clients.json` (добавление/список/редактирование/удаление).
- `ui_clients.py` — интерфейс раздела «Клиенты».

**Контент-план:**
- `content_plan.py` — генерация, построчная перегенерация, ручное редактирование, CSV-экспорт.
- `ui_content_plan.py` — интерфейс раздела «Контент-план».

**Сценарии рилсов:**
- `reels_script.py` — генерация текстового сценария и CRUD сохранённых сценариев.
- `ui_reels.py` — интерфейс раздела «Сценарии для рилсов».

**Обработка видео (не изменён):**
- `analyze_reference.py` — анализ видео-референса.
- `analyze_clips.py` — анализ сырых клипов.
- `match_scenes.py` — составление монтажного плана (EDL).
- `assemble_video.py` — сборка финального видео по EDL.
- `video_tab.py` — интерфейс раздела «Обработка видео».

**Посты и описания:**
- `post_text.py` — генерация текста поста и CRUD сохранённых постов.
- `ui_posts.py` — интерфейс раздела «Посты и описания».

**Реклама:**
- `ads.py` — генерация рекламных текстов и CRUD сохранённых объявлений.
- `ui_ads.py` — интерфейс раздела «Реклама».

**Прочее:**
- `requirements.txt` — зависимости Python.
- `packages.txt` — системные пакеты для Streamlit Community Cloud (устанавливает `ffmpeg`).
- `.streamlit/secrets.toml.example` — пример файла секретов для `st.secrets` (не хранит реальный ключ).
- `data/clients.json` — локальное хранилище клиентов (создаётся автоматически, не входит в git-репозиторий).
- `data/content_plans/`, `data/reels_scripts/`, `data/posts/`, `data/ads/` — по одному JSON-файлу
  на клиента в каждой папке (создаются автоматически, не входят в git-репозиторий).
